# metric_calibration

Floors, ceilings and noise for the metrics in `../` and a one-call test for "is this improvement real?".
The analysis and findings are in **[REPORT.md](REPORT.md)** (generated by `build_report.py` from `report_template.md` + `results/`).

| want to | run |
|---|---|
| compare a trained CLS-family checkpoint with raw DINOv2 (paired CI, % of range, smoothing- and whitening-equivalence) | `python compare.py --a ckpt:<last.ckpt> --b raw:dinov2 --seed-sd-json results/seed_sd_cls_family.json` |
| compare any two `(N,T,D)` latent arrays on the same clips | `python compare.py --a npy:a.npy --b npy:b.npy` |
| floors / decoys / ceilings for an encoder's trajectory metrics | `python calibrate_trajectory.py --encoders <names> --out results/trajectory_calibration.csv` |
| interpolation-planning ladder (static midpoint, ridge, oracles, noise ceiling) | `python calibrate_planning.py --encoders <names> --out results/planning_calibration.csv` |
| probe floors / noise / ceilings | `python calibrate_probes.py --encoder <name> --out results/probes/<name>.json` |
| skill ladder for a checkpoint | `python eval_skill_study.py --ckpt <last.ckpt> --name <n> --out-dir results/skill` |
| seed / epoch noise of a checkpoint family | train seeds with `train.pbs`, then `eval_noise_study.py` per checkpoint, `noise.seed_summary` / `noise.welch` |

Modules: `metrics_batch.py` (vectorised metric suite; `tests/test_metrics_batch.py` checks it against `compute_metrics_dict`), `references.py` (floors/decoys/smoothers/ceilings/reparametrisations),
`noise.py` (bootstrap, paired and cluster bootstrap, Welch, MDD), `signal_noise.py` (non-persistent-noise fraction), `oracles.py` (SFA, time read-out), `synthetic_latent.py` (known-SNR trajectories + closed forms),
`synth_videos.py` (known-motion clips), `extract_jitter.py` (frame-sampling test-retest).

CPU jobs: `ENV=lift SCRIPT=<py> ARGS="..." qsub -V run_cpu.pbs`; GPU jobs (need the `frozen-encoders` env): `ENV=frozen-encoders SCRIPT=<py> ARGS="..." qsub -V run_gpu.pbs`.
