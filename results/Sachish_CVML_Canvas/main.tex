% ---- Baseline-comparison color shorthands (used in experiments/*.tex tables) ----
% \good{...}: this cell beats BOTH the DINOv2 CLS and DINOv2 mean-patch baselines on a
% metric where the direction (higher/lower-is-better) is well defined, by a margin that
% looks like a real effect rather than run-to-run noise.
% \bad{...}: same, but worse than both baselines.
% Deliberately left uncolored when a cell beats one baseline but not the other (mixed,
% not a clean win/loss), when the metric has no well-defined better/worse direction
% (e.g. mean_norm, adjacent_l2_distance, norm_std_within_clip), or when the deviation
% from baseline is too small to be a real effect.
\newcommand{\good}[1]{\textcolor{green!55!black}{#1}}
\newcommand{\bad}[1]{\textcolor{red}{#1}}
